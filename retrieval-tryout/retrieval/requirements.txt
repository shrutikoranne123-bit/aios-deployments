# =============================================================================
# Retrieval service dependencies (lean, runtime-only).

# This is the dependency set for the RETRIEVAL API (retrieval_new.py +
# query_router.py + tool_store.py) and the service.sources.* / service.api_*
# modules it reuses for the database/api/cloud_storage tool kinds.
#
# It deliberately EXCLUDES the heavy ingestion stack (torch, docling,
# unstructured, pymupdf) which the retrieval path never imports. Versions are

# stay consistent.
#
# NOTE on optional connectors:
#   * transformers (services.tokenizer_service) is only imported when the
#     `api` tool kind runs through APISource. It is NOT installed here by
#     default to keep the image small. If you use `kind:"api"` tools, install
#     the "API tool kind" extras below.
#   * google-cloud-storage / azure-storage-blob are only needed for the
#     `cloud_storage` tool kind. Enable the "Cloud storage tool kind" block
#     if you use S3/GCS/Azure tools.
# =============================================================================
